What's running behind this page
  • ASR — your recording is sent to /api/transcribe, which calls Google Cloud Speech-to-Text with the or-IN locale.
  • MT — the Odia text is sent to /api/translate, which calls Google Cloud Translation (or → en).
  • TTS — the English text is sent to /api/synthesize, which calls Google Cloud Text-to-Speech and streams back an MP3.

Every stage is editable before it moves to the next — correct the Odia transcript, or rewrite the English translation, before it's spoken.
